Braces become indentation, and the type declaration is dropped — Python infers it at assignment.

One request, five stages

Every translation runs through the same pipeline, so the output is predictable and each step stays easy to reason about on its own.

01

Frontend

Source code, source language, and target language are packaged into a request.

02

Validator

Flags constructs outside the supported scope before anything is translated.

03

Parser

Breaks valid code into a structured, language-neutral representation.

04

Translation engine

Generates target-language syntax from the structured representation.

05

Explanation generator

Attaches a plain-language note to each changed line before returning the result.

What it actually does

No ambition to be a full compiler — just a dependable translator for the constructs students hit first.

Rule-based translation

A controlled engine covering six core constructs — variables, input/output, conditions, loops, functions, and arrays — built for accuracy over coverage.

Line-by-line explanations

Every converted statement carries a short note on what changed and why, so the target syntax actually clicks.

Scope validation

Constructs like exception handling are caught up front, with a plain warning instead of a broken or misleading result.

Side-by-side comparison

Source and translated code sit in parallel panes, so you can trace any statement across both languages at a glance.
